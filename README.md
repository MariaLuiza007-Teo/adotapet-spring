# AdotaPet: O Sol Nasce para Todos

Sistema web da ONG **O Sol Nasce para Todos**, de Itaituba (PA), feito com **Spring Boot**. O projeto junta o site da ONG a uma área de cadastro de animais, adotantes e adoções.

Este é um **projeto acadêmico e fictício**, desenvolvido para praticar Java e desenvolvimento web. Ele foi inspirado no trabalho da ONG, mas não tem vínculo oficial com a instituição.

## Tecnologias Utilizadas
* **Java 21** e **Spring Boot**
* **Spring Data JPA** com banco **H2**
* **Thymeleaf** para as páginas
* **HTML e CSS** do site original

## O que tem no projeto?
* **Site da ONG:** páginas de Início, Animais, Nossa História e Contato. Os animais vêm do banco de dados, e pela página de Contato é possível fazer um pedido de adoção.
* **Área da ONG:** cadastro, edição e exclusão de **Animais**, **Adotantes** e **Adoções**.

## Como executar
1. Importe o projeto no Eclipse em **File → Import → Existing Maven Projects**.
2. Rode a classe `AdotapetApplication` com **Run As → Java Application**.
3. Acesse **http://localhost:8081** no navegador.

O site original, só em HTML e CSS, está em: https://marialuiza007-teo.github.io/adota_pet/
